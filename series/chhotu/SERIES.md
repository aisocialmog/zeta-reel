## The comment rule (decides how each episode opens)
1. Before writing Day N-1, read Day N's comments on Instagram + YouTube. Count a vote when a top-level comment (not the page's own,
   not replies) says A / B, or clearly names an option ("padho", "chhupao", "message padh"). One vote per username; ignore unclear ones.
2. Compare the majority with that episode's CORRECT option (ledger below).
   - Majority = CORRECT → open on the correct path only ("Zyada tar ne A bola… aur sahi bola!"), story continues from it.
   - Majority = WRONG → first play the wrong path as a short "what if" (what would happen, with the consequence on the HUD —
     AURA drop / PHONE life lost), then rewind ("Par ruko… asli mein Chhotu ne ye kiya") and play the correct path; story continues
     from the correct path.
   - Tie or < 5 votes → treat as majority = correct, but show a 2-second wrong-path flash for fun.
3. Show the vote on screen in the first 3 s (e.g. "A 57% · B 43%") and shout out 1–2 real commenters by @handle (only handles,
   nothing else about them).
4. End with the next A/B question. The CORRECT option goes in the ledger the moment the episode is written.

## Wrong-path beat (user rule, from Day 97 on)
When the comment majority picked the WRONG option: open with a short "agar B choose karte toh..." beat, about 5–7 s (it can run a little longer). Show the funny, sad alternate version of what happens. Example for Day 98's B: Chhotu does it alone without Mishti, gets lonely, the ego balloon pops, he stares at the same mistake. Use a rewind effect, then cut to the correct path and carry on with the story.
